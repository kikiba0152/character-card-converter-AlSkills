# 角色卡转换_Bara Skill v1.3.0

> Bara特化版角色卡转换。从「角色卡转换 v2.3.2」分支。
> 输出格式：**JSON 骨架 + Markdown 内容**。

---

## 快速开始

上传一张 Bara 类型角色卡 PNG 或 JSON，Skill 自动完成。

---

## 与原版的区别

| 维度 | 原版 | Bara版 |
|------|------|--------|
| 肌肉描写 | 统一的体型描述 | 六大肌群分解（胸/臂/腹/背/腿/臀） |
| 体毛 | 体毛子项 | 体毛地图（胸/腹/阴/腿/腋） |
| 兽人特征 | 动态额外维度 | 强化：Knot/Rut/獠牙/口套 |
| 汗液/气味 | 可选 | 必须保留，正面描写 |
| 翻译 | 标准翻译 | Bara强化翻译表 |
| 标签 | 通用标签 | Bara专属标签体系 |
| 输出格式 | JSON | JSON骨架 + Markdown内容 |

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 🔥 肌肉群分解 | 胸/臂/腹/背/腿/臀 各肌群独立描写 |
| 🐺 兽人强化 | Knot/Rut/獠牙/耳/尾 完整保留 |
| 💧 体液细节 | 汗珠轨迹、前列腺液拉丝、精液浓稠度 |
| 🍑 Bara标签 | 肌肉崇拜/体型差/体毛癖/Knotting |
| 🏋️ 体型分类 | 健美型/熊系/精壮/肥壮/瘦肌肉 |
| 🎤 雄性化语气 | 粗犷/沙哑/直接 的对话风格 |
