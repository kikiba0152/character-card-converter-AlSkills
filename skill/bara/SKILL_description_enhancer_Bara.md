## 二、检查与补齐规则

### 2.1 核心原则

> **有则不动，缺则补齐。补齐来源：从 personality / scenario / first_mes 推断，不凭空捏造。**

### 2.2 检查流程（同原版四步）

```
Step D1: 解析 description 现有内容 → 提取已有子项 → 标记缺失
Step D2: 对缺失子项按优先级查来源（personality → scenario → first_mes → 推断）
Step D3: 必须项缺失→必须补齐；可选项→有来源则补；无来源→跳过
Step D4: 合并到 description，保持原有结构
```

### 2.3 推断规则

#### A. 通用子项推断（继承原版+新增Bara项）

| 缺失子项 | 推断来源 | 推断方法 |
|---------|---------|---------|
| 身高 | 体型分类+职业+personality | Bara参考：熊系/健美→185-200cm；精壮→175-185cm；瘦肌肉→170-180cm |
| 体重 | 体型分类+身高 | Bara参考：熊系/健美(185cm+)→100-140kg；精壮(180cm)→80-95kg |
| 体型分类 | personality+职业+场景 | 从肌肉描述关键词推断："肌肉虬结"→健美型；"壮硕厚实"→熊系；"结实但不过分"→精壮 |
| 体毛地图 | 体型分类+人种+personality | 见下方 Bara专属 体毛推断表 |
| 气味 | 职业+场景+personality | Bara增强：默认叠加"汗水+雄性麝香"基底，再叠加职业气味 |
| 汗液描写 | 场景+personality | 如场景含训练/战斗/高温/紧张→自动补齐汗珠轨迹描写 |
| 面容 | personality | 从性格推断表情："自信自恋"→嘴角得意笑容；"凶狠"→眉紧锁 |
| 穿着 | personality+场景 | Bara增强：默认"居家半裸/只穿内裤"，外出"宽松但肌肉撑满" |

## 五、注意事项

1-6 同原版。

7. **Bara子项触发条件判断**：先判断角色是否属于Bara类型（含肌肉/Bara/兽人/熊/壮汉标签），再决定是否触发Bara新增子项
8. **Knot不凭空添加**：只在犬科兽人角色上触发，人类/猫科/其他兽人不添加
9. **体毛地图必须补齐**：Bara角色默认触发，即使原卡无体毛描述也需按推断表补齐（除非原卡明确注明"无毛/光滑"）
10. **Rut不凭空捏造**：原卡无提及且无暗示则不添加
