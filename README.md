## 零、奥卡姆剃刀（最高优先级 · 凌驾一切规则）

> **「若无必要，勿增实体。」— 奥卡姆的威廉**

这是本 Skill 的**元铁律**。所有其他规则、习惯、经验、缓存、记忆均服从本节。

角色卡是用户的成品，不是 AI 的审计日志。写入角色卡的每个字段**必须对用户对话有直接贡献**。

### 三条铁律

| 铁律 | 含义 |
|---|---|
| **直接价值** | 每个字段对角色扮演有直接贡献 |
| **非决策外溢** | 判定依据/推演过程/公式验证 **仅存于 AI 内部或 tmp** |
| **非元信息污染** | Skill 版本/处理日期/AI 操作痕迹 **不得写入成品** |

### 输出前自检清单

```
[ ] 判定术语 → 仅结果入卡（"判定依据 / 三维投票 / 公式验证 / L级推断"→ 删）
[ ] AI 痕迹 → 仅 metadata 简记（"由 X 处理 / v1.2.0 / 修订要点"→ 删）
[ ] 拆分逻辑 → 仅内部 tmp（"原卡混杂了 X"→ 删）
[ ] 自检报告 → tmp 文件
[ ] creator_notes ≤ 80 字符
[ ] 无证据项 → 留白，不补模板
```

### creator_notes 规范

- ✅ 可写：原作者 / 角色定位 / 格式说明
- ❌ 禁写：Skill 名称版本 / 处理日期 / AI 决策记录 / 修订要点

## 一、通用底线（v2.5.0 新增）

### 性别中性原则

主 Skill **不为不同角色预设性别、身体结构、性爱风格或 NSFW 内容**：

- **不假设** — 不因无原文默认性别/性取向
- **不强加** — 不因无原文强制补齐器官/性爱偏好
- **不刻板化** — 禁止按"姓名→国籍""体型→器官尺寸"等映射
- **不替换** — 原卡明确设定的性向/PG级不得被"中和"

### 专题增强边界

主 Skill 仅做 **统一 V3 结构 + 字段归位 + 翻译 + 留白**。肌肉描写强化、Bara 兽人维度、机甲扩展等由专题 Skill 承担。

### 证据型补齐

仅从当前原卡其他字段归位或概括；无证据时保留合法空值。补齐禁区：不编造数值、不发明身份、不预设身体、不专题污染、不串卡。

## 快速开始

上传一张角色卡 PNG 或 JSON，Skill 自动完成：

```
PNG/JSON → 提取 & 语言检测 → 翻译 → 智能拆分 → 证据型补齐
         → 通用性检查 → 奥卡姆自检 → V3 JSON + PNG 回嵌
```

**输出位置**：`/sdcard/Download/Operit/charactercard/`

## 核心能力

| 能力 | 说明 |
|---|---|
| 🌐 **多语种翻译** | 自动检测非中文内容，翻译为简体中文 |
| 🧠 **智能拆分** | 冗余内容拆分到正确字段 |
| ✨ **证据型补齐** | 仅从当前原卡归位或概括；无证据则留白 |
| 🔍 **奥卡姆自检** | 输出前过 §0 清单，确保零 AI 痕迹外溢 |
| 🖼️ **PNG 回嵌** | 保留原头像，替换内置 JSON 为中文 V3 |

## 执行流程

```
Step 0   格式判断（PNG / JSON）
Step 1   提取 + 语言检测
Step 2   翻译 + 拆分 + 证据型补齐
Step 3   构建 V3 JSON 并输出
Step 3.5 奥卡姆自检（scripts/occam_selfcheck.py）— 回嵌前强制关卡
Step 4   PNG 回嵌（scripts/embed_chara_to_png.py）
```
