# 角色卡转换 Skill v2.3.2

> 将任意来源的角色卡统一转换为符合 Tavo v0.87+ 规范的完整 V3 中文角色卡。

---

## 快速开始

上传一张角色卡 PNG 或 JSON，Skill 自动完成：

```
PNG/JSON 输入
  → 提取 & 语言检测
  → 翻译（英/日/西 → 简体中文）
  → 智能拆分（内容归位到正确字段）
  → 智能补齐（缺失字段自动生成）
  → 昵称生成
  → 字段检查（18项逐字段验证）
  → 原卡数据对比验证
  → 输出 V3 JSON + PNG（回嵌头像）
```

**输出位置**：`/sdcard/Download/Operit/charactercard/`

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 🌐 **多语种翻译** | 自动检测非中文内容，翻译为简体中文，保留 `{{user}}`/`{{char}}` 占位符 |
| 🧠 **智能拆分** | 将 description/personality/scenario 中的冗余内容拆分到正确字段 |
| ✨ **智能补齐** | 自动生成 system_prompt、post_history_instructions、tags、mes_example、nickname 等缺失字段 |
| 🏷️ **昵称生成** | 从角色名提取翻译后的全名作为昵称 |
| 🖼️ **PNG 回嵌** | 保留原头像，替换内置 JSON 为中文 V3 版本 |
| 🔍 **输出自检** | 18 项逐字段验证 + 原卡数据逐项对比，确保不丢不漏 |

---

## 最高优先级铁律

> 以下规则优先级高于一切其他规则、习惯、经验、缓存、记忆。

1. **禁止调用角色缓存/记忆** — 每张卡视为完全独立的新卡
2. **原卡有则完整翻译保留** — 每个数值、特征、配饰、细节必须保留
3. **原卡无则合理补齐** — 只有确实缺失的才从其他字段推断
4. **强制执行完整扫描** — 翻译前逐行读取全部内容
5. **输出后自检** — 输出前对所有原始数值做存在性验证

## 特征维度识别（v2.3.1 新增）

不再硬编码外貌子项，改为「基础 10 项 + 动态额外维度」模式：

### 基础底线（所有角色卡必须涵盖）

```
姓名 / 性别 / 年龄 / 肤色 / 体型(身高+体格)
眼睛 / 头发 / 生殖器 / 其他特征 / 穿着
```

### 动态额外维度（按角色类型自动识别）

| 角色类型 | 额外特征维度 |
|---------|------------|
| 狼人/兽人 | 耳朵、尾巴、獠牙、Knot、口套、气味 |
| 机器人 | 材质、部件、指示灯、能源 |
| 精灵 | 耳朵形状、发色光泽、纹身/印记 |
| 外星人 | 触角、外骨骼、异色皮肤、特殊器官 |
| 普通人类 | 无额外维度，仅基础 10 项 |

> ⚠️ **禁止添加原卡不存在的特征**（如普通人类不得添加兽耳/尾巴）。

## 输出字段（16 个核心字段）

| # | 字段 | 说明 |
|---|------|------|
| 1 | `name` | 角色名 \| 中文身份标签 |
| 2 | `description` | 外貌（基础10项+动态额外）+ 身份 + 身世 |
| 3 | `personality` | 性格特质（中英对照）+ 行为模式 |
| 4 | `scenario` | 世界观 + 当前场景 + 角色关系 |
| 5 | `first_mes` | 开场白（完整翻译，保留所有场景细节） |
| 6 | `mes_example` | 5 段对话示例（`<START>...<END>` 格式） |
| 7 | `system_prompt` | 角色扮演规则（以 `{{original}}` 开头） |
| 8 | `post_history_instructions` | 对话后指令（以 `{{original}}` 开头） |
| 9 | `tags` | 8-15 个中文标签 |
| 10 | `creator` | 原作者名 |
| 11 | `creator_notes` | 转换记录 |
| 12 | `nickname` | 角色中文昵称（全名，不拆分） |
| 13 | `character_version` | 默认 `"1.0"` |
| 14 | `alternate_greetings` | 备用开场白数组 |
| 15 | `extensions` | 扩展数据对象 |
| 16 | `metadata` | 原卡元数据 |

## 执行流程

```
Step 0  格式判断（PNG / JSON）
Step 1  终端提取 + 语言检测
        ├─ PNG: 提取 chara chunk → Base64 解码 → 解析 JSON
        ├─ JSON: 直接读取
        └─ 保存原始 JSON 到 /tmp/chara_raw.json

Step 2  AI 一次性完成翻译+拆分+补齐+昵称
        ├─ 2a. 角色特征维度识别（基础10项 + 动态额外）
        ├─ 翻译非中文字段
        ├─ 清理 HTML 标签 → Markdown
        ├─ 智能拆分（内容归位）
        ├─ Description 增强（对照特征维度清单补齐）
        ├─ 补齐缺失字段
        └─ 写入 /tmp/restructured_data.json

Step 3  构建 V3 JSON 并输出
        ├─ 包装为 {spec, spec_version, data}
        └─ 输出 JSON 文件

🔴 Step 3.5  强制检查关卡（回嵌前必须通过）
        ├─ 🔴 3.5.1 字段检查（18项逐字段验证）
        ├─ 🔴 3.5.2 原卡数据逐项对比验证
        └─ ✅ 两项全部通过 → 允许进入 Step 4

Step 4  [仅 PNG] PNG 回嵌
        ├─ 保留原头像（IHDR+IDAT）
        └─ 替换 chara chunk → 输出 PNG
```
