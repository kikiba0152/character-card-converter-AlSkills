# 角色卡转换 Skill

Operit 平台的 Skill，用于将任意来源的角色卡（SillyTavern V1/V2、TavernAI、Character.AI JSON 等）**统一转换为符合 Tavo v0.83.1+ 严格规范的 V2 角色卡**，并自动检测语言进行中英翻译。

## ✨ 功能特性

- 🔍 **中英自动检测**：自动识别角色卡内容的语言（中文/英文/中英混合）
- 🌐 **智能翻译**：对纯英文内容自动翻译为简体中文，保留角色语气和性格特征
- 🖼️ **PNG 角色卡支持**：直接读取 PNG 中嵌入的角色卡数据（tEXt chunk）
- 🔓 **Base64 自动解码**：自动检测并解码 Base64 编码的 JSON 数据（SillyTavern 导出常见格式）
- 📦 **PNG 回嵌**：翻译后的中文角色卡可回嵌到原 PNG 头像中，生成完整的中文 PNG 角色卡
- 📐 **V2 严格规范**：输出完全符合 Tavo v0.83.1+ 的 V2 角色卡结构
- 🚫 **零外部依赖**：所有提取与转换逻辑由 AI 通过终端内联 Python 脚本执行

## 📥 输入格式支持

| 输入类型 | 说明 |
|---------|------|
| **PNG 角色卡** | SillyTavern 导出的 PNG 角色卡，chara 字段支持明文 JSON 和 Base64 编码 |
| **JSON 文件** | `.json` 后缀的角色卡文件 |
| **纯 JSON 文本** | 直接在对话中粘贴的 JSON 内容 |

## 📤 输出格式

| 输入类型 | 输出 |
|---------|------|
| PNG 角色卡 | PNG（保留原头像，替换角色卡数据为中文 V2 JSON） |
| JSON 文件（英文） | `{角色名}_V2_card_CN.json` |
| JSON 文件（中文） | `{角色名}_V2_card.json`（不重复翻译） |

## 🚀 使用方法

1. 在 Operit 中激活「角色卡转换」Skill
2. 上传角色卡（PNG 或 JSON）
3. Skill 自动判断输入格式并执行对应流程：
   - **PNG**：提取 → Base64 检测 → 语言检测 → 翻译 → 回嵌
   - **JSON**：读取 → 语言检测 → 翻译 → 输出 JSON
4. 输出文件保存在 `/sdcard/Download/` 目录

## 🔄 执行流程

```
用户上传角色卡
    │
    ▼
前置检查 0.1：输入格式判断（最高优先级）
    ├─ .png → PNG路径
    │   ├─ 提取 chara/ccv3/text chunk
    │   ├─ Base64 自动检测与解码
    │   ├─ 语言检测
    │   ├─ 翻译（如需）
    │   └─ 回嵌到原 PNG
    └─ .json / 纯文本 → JSON路径
        ├─ 解析 JSON
        ├─ 语言检测
        ├─ 翻译（如需）
        └─ 输出 JSON 文件
```
